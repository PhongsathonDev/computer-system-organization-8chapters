# CS:ORG — แบบฝึกหัดเติมคำ 8 บท 

เว็บไซต์แบบฝึกหัดโครงสร้างระบบคอมพิวเตอร์ (020413106) แบบไฟล์เดียว
ไม่ต้องติดตั้ง dependencies ไม่ต้อง build และไม่ต้องมี backend

## ไฟล์ในโฟลเดอร์นี้

- `index.html` — ตัวเว็บทั้งหมด รวม HTML, CSS, JavaScript และชุดคำถาม
- `.nojekyll` — ปิดการประมวลผล Jekyll ของ GitHub Pages

## วิธี host ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เลือก Public)
2. อัปโหลด **ไฟล์ทั้งหมดในโฟลเดอร์นี้** ไปไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. กด **Save** แล้วรอประมาณ 1–2 นาที
6. เปิดเว็บที่ `https://<username>.github.io/<repository>/`

## การอัปเดตเว็บ

แก้ไข `index.html` แล้วอัปโหลดทับไฟล์เดิมใน repository
GitHub Pages จะแสดงเวอร์ชันใหม่ให้เองภายในไม่กี่นาที

## ตรวจคุณภาพข้อสอบ 4 ตัวเลือก

- ชุดคำถามอยู่ใน `assets/js/multiple-choice*.js` ครบ 472 ข้อใน 8 บท (ครอบคลุมวัตถุประสงค์เชิงพฤติกรรมทั้งหมด 236 ข้อ ข้อละอย่างน้อย 2 คำถาม)
- ใช้ศัพท์ไทย–อังกฤษควบคู่กัน โครงสร้างตัวเลือกคู่ขนาน ไม่ทิ้งร่องรอยโครงสร้างหรือวงเล็บในตัวเลือกที่ถูกต้อง และตัวลวงอิงจากความเข้าใจผิดที่พบบ่อย (Common Misconceptions)
- เฉลยแต่ละตำแหน่งต่างกันไม่เกิน 1 ข้อในแต่ละบท และกระจายสม่ำเสมอเท่ากันสมบูรณ์ทั้งระบบ (ข้อ ก, ข, ค, ง มีตำแหน่งละ 118 ข้อ หรือ 25% พอดี) โดยไม่เรียงคำตอบซ้ำเกิน 2 ข้อติดกัน
- ตรวจอัตโนมัติด้วย `node --test tests/multiple-choice.test.cjs` (ต้องมี Node.js; ตัวเว็บยังเปิดได้โดยไม่ต้องติดตั้ง)
- การทดสอบความยาวและวงเล็บเป็นเพียงตัวช่วย ต้องทบทวนความถูกต้อง ความสมเหตุสมผล และความซับซ้อนของภาษาด้วยเมื่อแก้ข้อสอบ
- ชุดปรับปรุงใช้ที่เก็บคำตอบ `csorg_mcq_chapterN_v2` แยกจากชุดเดิม เพื่อไม่ให้ตำแหน่งคำตอบเก่าส่งผลต่อคะแนนใหม่ โดยไม่ลบข้อมูลเดิมและไม่กระทบแบบเติมคำ
